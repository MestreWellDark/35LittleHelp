# D35E Little Helper

Quality-of-life module for Foundry Virtual Tabletop's **D35E** system.

## Target

- Foundry VTT 13
- D35E 3.1.0
- Module ID: `d35e-little-helper`

## Status

Initial development. This is a clean D35E implementation inspired by the feature set of Koboldworks' PF1 Little Helper, with D35E-specific data paths, sheets, rolls, and chat cards.
